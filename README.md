# Fan Yang — Academic Website

This repository contains the source for [fanyang-psy.github.io](https://fanyang-psy.github.io/), the bilingual academic website of Fan Yang, Ph.D.

## Sections

- Home and about
- Research
- Selected publications
- Curriculum vitae
- Contact and academic profiles
- Separate concise Japanese profile

## Updating the site

The site is intentionally dependency-free. Edit `index.html` for English content, `ja.html` for the Japanese profile, `styles.css` for presentation, and `script.js` for the mobile menu and theme controls. Changes pushed to the `main` branch are published from the repository root with GitHub Pages.

Publication entries use APA 7th–style references. Before adding an item, verify its author order, year, title, journal details, and DOI against the publisher or researchmap.

## Source notes

The initial content was compiled from Fan Yang’s public Waseda University profile, researchmap record, ORCID-linked publication pages, and existing academic website. The portrait is based on the public faculty photograph on the Waseda University psychology course website and is stored locally in `assets/`.
